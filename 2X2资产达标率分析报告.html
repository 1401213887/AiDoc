⑦ 判定口径说明

R1 MobileMinLOD > 0 —— 显式设置了移动端 LOD 降级起点（0 视为未降级配置，不计入有效）。

R2 LOD0 < 300 —— 低面数资产无需 LOD，直接视为有效。

R3 LOD0 ≥ 300 且 LOD1-6 全为 0 —— LOD 缺失（移动端降级时无 LOD 可切）。

移动端有效 = R1 或 R2。LOD 缺失率 = R3 命中数 / 总数。

注：LOD 面数来自扫描时的网格 LOD 层级统计，"面数一致"不绝对等于"几何一致"，最终处置前建议在 Content Browser 核对资产引用。
