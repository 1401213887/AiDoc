一、核心结论速览

渲染策略

  • 移动端 Mobile Deferred + Subpass（Vulkan）
  • 低端机回退 Forward
  • 大世界异步流送，无明显 loading

核心技术

  • 水墨美学：色彩偏柔，描边细而不锐利
  • 地形 GPU Driven + Virtual Texture
  • 大量自然要素（雨、雪、雾、风）

预算/Format

  • SceneColor R11G11B10
  • G-Buffer 仅在 tile memory（Subpass）
  • Shadow 2~3 级 CSM
燕云的工程定位
网易 Messiah 引擎是为"跨端开放世界"准备的，目标对标手游、PC、主机统一发版。燕云十六声是 Messiah 在大世界品类的代表作之一，移动端走 Mobile Deferred 路径 是关键决策——这与三角洲移动端的高端档思路一致。

三、Pass 顺序与 RT

Pass 1 · ShadowMap

3 级 CSM（高档），分辨率 1024² ~ 2048²。低档 2 级 1024²。

Pass 2 · GBuffer（tile memory）

Mobile Deferred 在 Subpass 内写 GBuffer 不写主存。GBuffer Format 高度精简（B8G8R8A8 + R10G10B10A2）。

Pass 3 · Lighting（tile memory 直读）

主光 + 静态局部光。无 SSAO / SSR（移动端）。

Pass 4 · Sky / Atmosphere

大气散射 LUT，远景体积云。

Pass 5 · Translucency

水、特效、雨/雪粒子。

Pass 6 · PostProcess

Bloom + Tonemap + 色调（中国风偏柔的色彩曲线）。

四、大世界场景

地形

  • GPU Driven Heightmap，所有地形 Patch 由 GPU 决定 LOD
  • SVT 多层贴图（草、土、石、雪等 6+ 层）
  • Decal 大量使用，地表脚印/痕迹/血迹
  • 移动端低档退化为静态 Mesh Patch + 单层贴图

建筑

  • 古风木构建筑，多 Mesh 拼接
  • Atlas 共享贴图，大量复用
  • 室内"假"光影：Light Probe + 局部 Cubemap，无实时 GI

植被

  • 近：完整 Mesh + 风动顶点偏移
  • 中：LOD 简化 + Billboard 树叶
  • 远：Imposter（多角度烘焙）
  • "竹林"是燕云特色，密集竹竿用 Mesh Instancing 大批量绘制

HLOD

  • 整片山谷烘焙为单 Mesh + 4K Atlas
  • 切换距离按机型分档
  • HLOD 之间过渡用 dither fade

五、天气与时间系统

天气是核心卖点
燕云十六声主打"国风四时风物"，天气 + 季节 + 时间是核心体验。技术上需要大量动态系统。
系统实现移动端代价
大气散射预计算 LUT，运行时采样低
体积云Ray March（PC）/ 贴图近似（移动）中
雨粒子 + 屏幕空间湿度（高档）中
雪地表覆盖度（World Y + Normal Y） + 粒子中
雾Distance Fog + Volumetric Light Shaft（高档）高
季节切换植被 Material 切换调色板 + 地表覆盖度参数低

六、水体与笔触感

  • 湖面：Gerstner 波 + 屏幕空间反射（高档）
  • 河流：Flow Map 控制水流方向
  • 水墨笔触：水边 Foam 用噪声贴图模拟"晕染"，与一般 SSR 水边白沫不同
  • 角色入水：动态 RT 写入 displacement，移动端简化为单点扰动

七、武侠战斗特效

  • 剑光 Trail：Mesh Trail + 流光贴图，飘逸感是核心，避免硬边
  • 气功 / 内力：屏幕空间扭曲 + 浅色调 Glow，类似"内功波"
  • 轻功：高速移动时全屏 Vignette 扩张 + 速度线（轻量，非绝区零式漫画风）
  • 命中冲击：屏幕震动 + Bloom 暴增，配合武侠"击中要害"的爽感

八、移动端性能策略

分档

  • 低/中/高/超高，旗舰机推 60/120 fps
  • 低档关 SSR/SSAO/体积云/动态雪 → 改为静态贴图
  • 超高档对标 PC 中档

开放世界 streaming

  • 分块 1km × 1km，前后各 2 块预读
  • 角色队伍 + NPC 资源 LRU 缓存
  • 纹理 Mip Streaming，距离决定 Mip 上限

带宽与发热

  • SceneColor R11G11B10 + GBuffer 不写主存（Subpass）
  • RDG Pass 合并，减少切换次数
  • 5 分钟后温度高自动降分辨率（DRS）

九、关键启示

对开放世界手游

  1. Mobile Deferred + Subpass 是高画质开放世界的最优解
  2. SVT + GPU Driven 地形是大世界标配
  3. Imposter + HLOD 解决远景植被和建筑

对国风/写实项目

  1. 水墨美学的关键是"边缘晕染"，不是高分辨率
  2. 天气系统应分档实现，避免低端机被"四时风物"压垮
  3. 战斗特效要"飘"不要"硬"，Trail 与 Glow 是核心
