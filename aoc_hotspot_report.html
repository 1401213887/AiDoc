🩺 诊断

  • GPR 压力严重（44 VGPR）：导致 ALU fiber occupancy 仅 25%，大量 GPU 算力闲置。优化方向：将 varyings / 中间计算改为 half 精度（fp16），减少 VGPR 占用。
  • Exposed Long Latency = 45.6%：shader 大量周期在等待访存（纹理采样 / buffer load）。检查纹理采样次数，考虑合并采样、用 sampler2DArray 代替独立纹理、开启 Anisotropic filtering 提高 cache 命中率。
  • ALU 16-bit 占比低（1592 / 9581 ≈ 16.6%）：Adreno 740 的 16-bit ALU 吞吐是 32-bit 的 2x。将不需要高精度的计算（颜色叠加、UV 偏移等）改为 half，可显著降低 ALU 周期。
  • 无 Scratch Memory：好消息，没有 register spilling 到 VRAM，GPR 优化空间在纯寄存器层面。

✅ 优化建议（按优先级）

  1. 将 DeferredShading PS 中输入纹理的采样结果、中间 lighting 计算全部改用 half4/half3（fp16），目标将 GPR 从 44 降到 ≤32，occupancy 提升到 ≥50%。
  2. 减少纹理采样次数：检查是否有重复采样同一张 GBuffer 纹理的情况，用临时变量 cache 结果。
  3. 将循环内的 ALU 计算改为 half 精度，利用 Adreno 的 16-bit ALU 双发能力。
  4. 如果此 shader 使用了分支（flow control=217），检查是否可以 flat/branch 化，减少 divergence。

📋 RenderDoc GUI 导出脚本

将以下脚本粘贴到 RenderDoc → Window → Python Shell 中运行，导出所有热点 shader 的 .spv 文件到工作目录。 导出后重新运行本 skill 即可获得完整 AOC 分析报告。 

import renderdoc as rd
controller = rd.GetCurrentReplay()

hotspots = [
    (3796, "pixel"),     # DeferredShading PS (已分析)
    (2324, "pixel"),     # ShadowProjection PS
    (4105, "pixel"),     # TAA PS
    (2279, "pixel"),     # AO_HorizonSearch PS
    (4116, "pixel"),     # Tonemap PS
    (2402, "pixel"),     # MobileToonOutline PS
    (2289, "pixel"),     # AO_SpatialFilter PS
    (4129, "pixel"),     # NaiveUpscale PS
    (3980, "pixel"),     # BloomSetup PS
    (649,  "compute"),   # VSM Update CS
    (685,  "compute"),   # MMHRenderShadowDepths CS
    (2333, "compute"),   # ShadowProjection MMHFeedback CS
]

out_dir = "C:/Users/djangozhang/Desktop/MobileWorkSpace/shaders/"
import os
os.makedirs(out_dir, exist_ok=True)

for eid, stage in hotspots:
    try:
        refl = controller.GetShaderReflection(eid, stage)
        if refl and refl.rawBytes:
            spv = refl.rawBytes
            fname = f"{out_dir}eid{eid}_{stage[0]}s.spv"
            with open(fname, "wb") as f:
                f.write(bytes(spv))
            print(f"[OK] eid={eid} {stage} {len(spv)} bytes -> {fname}")
        else:
            print(f"[SKIP] eid={eid} {stage}: no reflection")
    except Exception as ex:
        print(f"[ERR] eid={eid} {stage}: {ex}")

print("Done. Files in", out_dir)
