一、核心结论速览

渲染策略

  • 移动端 UE4 Mobile Forward 改造
  • 角色 NPR + 场景偏 PBR 的混合体系
  • 大量开放世界元素：水、植被、地形精度对标 PC

核心技术

  • 角色：双 Ramp + Anisotropic 头发
  • 场景：Triplanar + 多层 Splat + Decal
  • 水体：屏幕空间反射 + Caustics + Foam

预算/Format

  • SceneColor R11G11B10
  • Shadow 2 级 CSM 1024²
  • 移动端禁用 Lumen / Nanite
鸣潮的工程画风
鸣潮是少数主流 NPR 二次元用 UE 而非 Unity 的产品。这给它带来：① 渲染管线与场景流送对标 PC 主机；② 但同时 UE 移动端的 NPR 工业化基础不如 Unity，需要额外工程投入。

二、UE 改造与移动管线

为什么选 UE
库洛技术栈延续自《战双帕弥什》，对 UE 的渲染层有较深定制经验。UE 的 RDG（Render Graph）+ MobileForward 路径更适合开放世界，便于做 streaming 与 LOD。
UE 模块鸣潮改造点
MobileBasePass替换 NPR 光照模型，加入 Ramp + 描边
Material Editor支持 NPR 节点（Anisotropic Hair、Face SDF 等）
Light System移动端关闭 Movable PointLight，改静态/Stationary
Shadow2 级 CSM，禁用 Distance Field Shadow
PostProcess移除 SSAO/SSR/AutoExposure 默认实现，自研轻量替代
RDG对 Mobile Forward 路径精简，合并部分 Render Pass 减少切换

三、Pass 顺序与 RT 布局

Pass 1 · ShadowMap

2 级 CSM，1024²。移动端高档开 RVT shadow（仅地面静态阴影），免去每帧绘制大场景投影。

Pass 2 · Depth Prepass

角色 + 大型建筑写 Z，便于后续 Soft Particle / Decal Z-test。

Pass 3 · BasePass

地形 → 植被 → 建筑 → 装饰 → 角色，按距离与 LOD 分桶。NPR 与 PBR 通过 Material Domain 区分，使用同一 Pass 但不同 shader。

Pass 4 · Outline

背面外扩描边，距离衰减。低档可关闭。

Pass 5 · Atmosphere / Fog

体积雾用屏幕空间近似，仅高档启用。

Pass 6 · Translucency

水、玻璃、技能特效。水体最贵，常单独走 Pass 以便后处理 mask。

Pass 7 · PostProcess

Bloom + Tonemap + Color Grading。移动端默认关 SSAO/SSR。

四、角色 NPR 与高光带

双 Ramp 策略

  • Ramp 1：基础阴影分界（暗部颜色）
  • Ramp 2：暗部内部细分（次表面散射近似）
  • 结合 Material ID（皮肤/布料/金属）选择不同 Ramp

头发 Anisotropic

  • 切线沿头发方向（vertex tangent）
  • 2 层高光：底层白色，顶层角色专属调色
  • 用噪声贴图调制高光位置，避免"塑料感"
  • 高档加 头发自阴影 RT，低档关

面部

  • SDF 面部贴图（与原神同思路）
  • 瞳孔单独 Mesh，加视差偏移以模拟立体感
  • 嘴部高光用 Mask 控制，避免普通 NdotL 时嘴唇反光过强

五、开放世界场景

地形

  • 4~6 层 Splat + Triplanar 砾石
  • 移动端用 SVT 压缩多层贴图带宽
  • 地表 Decal 大量使用（脚印、痕迹、苔藓）

植被

  • 大量 GPU Instancing
  • 风场模拟：CPU 高度 + Vertex 偏移
  • 远景树 Imposter

水体

  • 主流水面用 SSR（高档）/ Cubemap（低档）
  • Caustics 焦散贴图 UV 滚动
  • 水边 Foam 通过 Depth Buffer 差值检测

天空 / 大气

  • Sky Atmosphere（UE 自带）+ 自定义云层
  • Volumetric Cloud 仅 PC，移动端用贴图近似

六、动作战斗特效

鸣潮战斗的视觉重点
连段切换/暴击/QTE 反应快，需要"瞬间炸裂的特效"，但又不能像绝区零那样满屏 Halftone（产品定位是写实风偏 NPR）。
  • 武器轨迹：Mesh Trail + 沿轨迹采样 Emissive 贴图
  • 命中冲击：屏幕空间径向波浪 + Chromatic Aberration（瞬间）
  • 共鸣释放：切相机 + 电影级 DOF + Bloom 暴增
  • 属性变奏：火/冰/雷/气/物理/光/暗，每属性独立调色 LUT

八、移动端性能策略

分档

  • 低/中/高/极高，旗舰机推 60/120 fps 双档
  • 低档关 SSR/SSAO/DOF/体积雾，关 Caustics，关 Imposter→直接消失
  • 极高档对标 PC 中等画质

开放世界 streaming

  • UE 的 World Composition + Level Streaming
  • 分块 1km × 1km，前后 3 块预加载
  • 纹理 Mip Streaming，距离越远越高 Mip

UE 移动端坑点

  • Mobile Forward 默认对 RDG 支持不佳，库洛改造了 Pass 合并
  • Vulkan 上 PreRotation 必须开，否则竖屏物理朝向会引入 Blit
  • 动态光源在移动端代价高，控制场景内 Movable Light ≤ 4

九、关键启示

对 UE 系 NPR 项目

  1. UE 移动端 NPR 需要自己撸基础设施，不能指望引擎给
  2. 双 Ramp 比单 Ramp 自由度更高，对暗部细节更可控
  3. RDG / MobileBasePass 改造是性价比最高的优化点

对开放世界项目

  1. 水体的 SSR 性价比有限，Cubemap 在低档够用
  2. Imposter 是远景植被必备
  3. SVT 在 UE 中是地形多层 Splat 的关键，否则 sample 数爆炸
