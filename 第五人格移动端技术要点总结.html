一、核心结论速览

渲染策略

  • Unity 前向渲染，长期未升级到 SRP（兼容性优先）
  • 大量 烘焙 Lightmap，运行时几乎无动态 GI
  • 静态相机 + 部分动态相机视角

核心技术

  • 哥特美学：高对比 + 紫色调 + 描边
  • 角色 NPR：Ramp + 描边 + 简化 PBR
  • 地图 Atlas + Mesh Instancing

预算/Format

  • SceneColor RGBA8 LDR（多数档位）
  • Shadow 1 级 CSM 或 Blob
  • 分辨率 480P~720P 自适应
第五人格的特别之处
作为 7 年长线运营的产品，第五的渲染压力不在画质上限（图形 API 也未升 Vulkan 主流），而在主题/赛季/联动皮肤的快速产出。视觉品牌"哥特暗黑"已成为产品资产，技术决策围绕这套美学服务。

二、哥特风格的工程实现

视觉元素实现
整体偏暗Lightmap 全局压低亮度 + Tonemap 偏冷紫
高对比剪影角色描边强 + 远景"剪影化"贴图
纸娃娃质感角色面部立体感降低，类似平面绘画
烟雾 / 蒸汽大量粒子 + 屏幕空间扰动（高档）
哥特建筑尖顶教堂、马戏团、医院、庄园主题

三、Pass 顺序与 RT

Pass 1 · ShadowMap（中档及以上）

1 级 CSM 或 Blob，分辨率 512²。

Pass 2 · BasePass（前向）

地形 → 建筑 → 道具 → 角色。Lightmap 直采。

Pass 3 · Outline

角色描边，以及部分关键道具（板/窗/密码机）描边。

Pass 4 · Transparent

烟雾、雨滴、技能特效、UI 前粒子。

Pass 5 · UI

1v4 信息密度高（队友状态、任务进度、技能 CD），UI 单独优化。

Pass 6 · PostProcess（条件）

Bloom + 紫色调 Tonemap，低档关。

四、角色风格化

风格化 PBR

  • Half-PBR：BaseColor + Mask（Metallic/Smoothness/AO）
  • Ramp 调制 NdotL，制造卡通明暗分界
  • Emissive 通道用于发光部位（眼睛、技能标志）
  • 描边背面外扩，宽度按距离衰减

面部

  • 面部贴图为主，几乎无 SSS
  • 大量"面具"角色：面具是独立 Mesh，与脸部分离
  • 表情用 Blend Shape，约 20 个

皮肤系统

  • 主线皮肤、赛季皮肤、联动皮肤（与 IP 合作）
  • 每个皮肤可改 Material + 部分骨骼，无需重做模型
  • 典型皮肤升级：BaseColor + Emissive + 局部 Mesh 替换

五、地图与道具

地图设计

  • 地图主题：庄园、医院、马戏团、月亮河公园、罗夏教堂等
  • 每个主题独立 Lightmap，运行时不混光照
  • 地图大小约 100m × 100m，比开放世界小很多

关键道具

道具渲染特点
密码机多个高复用模型，状态切换通过 Material 参数
板Mesh 简单，命中判定与渲染解耦
窗翻越动作高复用，Mesh 简单
地下室/狂欢之椅剧情交互，重要场景，特效预算高
大门胜利通关点，离场动画用全屏遮罩

六、技能与状态特效

  • 监管者技能：每个监管者有专属 5~8 个技能特效，主题感强
  • 求生者状态：受伤、濒死、起身——通过角色 Material 调色和 Emissive 表达
  • 恐惧震慑：屏幕空间紫色 Vignette + 心跳声同步
  • 密码机进度：进度条用屏幕空间圆环，悬浮于密码机上方

七、非对称对抗的渲染挑战

非对称玩法的特殊点
1 监管者 + 4 求生者，视角不对等——监管者第一人称视角，求生者第三人称背后视角。
这要求渲染管线对两套视角同时优化，且裁剪/LOD 决策完全不同。
视角视野优化重点
监管者第一人称FOV 90°，向前近距离手部细节、技能特效
求生者第三人称FOV 70°，背后跟随角色背面、左右遮挡物体
队友视角（旁观）切给其他求生者简化精度，主要看进度

八、长线运营的优化

Shader 变体治理

  • 7 年皮肤/赛季积累，shader 变体可达数千
  • 新皮肤 Material 走"模板系统"，不允许新增 shader 变体
  • 变体 dump 在每次发版前自动检查，超阈值需评审

包体与 AB

  • 核心包瘦身，皮肤/赛季均 AB 化
  • 赛季活动用动态下载，活动结束自动清理
  • 跨赛季资源做"档案归档"管理

分档

  • 低/中/高，目标机型从 SD615 ~ SD8 Gen3
  • 低档关 Bloom/Shadow/SSAO，分辨率降到 480P
  • 高档：720P + Bloom + Shadow CSM 1 级

性能瓶颈

  • 5 玩家同屏 + 大量动效（板、窗、密码机），CPU 是瓶颈
  • UI 渲染开销显著，尤其是大量 HUD 元素
  • 烟雾/雨等粒子系统是 GPU 主开销

九、关键启示

对长线风格化产品

  1. 美术品牌一旦确立，技术决策应"加固品牌"，而非追新
  2. 皮肤系统是营收核心，必须做到 Material 模板化
  3. Shader 变体治理是 5+ 年项目必修课

对非对称竞技

  1. 不对等视角需要分别优化
  2. UI 信息密度高，UI 渲染要专项优化
  3. 5 人同屏 ≠ 5 角色全 LOD0，远程队友可大幅简化
