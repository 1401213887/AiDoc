一、核心结论速览

渲染策略

  • 移动端 前向渲染 + 自定义 SRP
  • 角色 NPR，场景 半 PBR
  • 跨平台共享美术资产（差异在档位参数）

核心技术

  • 角色：Ramp 贴图卡通光照 + 多层描边
  • 地形：Tessellation + Triplanar + Virtual Texture（高档）
  • 植被：风场 + GPU Instancing + Imposter（远）

预算/Format

  • SceneColor R11G11B10 移动端 HDR
  • 角色 RT 单独 1 张（Outline 用）
  • Shadow 2~3 级 CSM 1024²
总体取舍
原神最大的工程挑战不是单帧画质，而是 跨设备一致性——同一个角色在 PS5 和小米 11 上看起来要"是同一个 Lumi"。这驱动了它在 NPR 体系上做逻辑参数化，而不是平台手写一份。

二、SRP 自定义管线

为什么不用 URP
Unity URP（轻量管线）对 NPR 描边、Ramp 光照、跨平台档位的支持很弱。原神团队选择 SRP（可编程渲染管线） 自己写，这样阴影、Pass 顺序、RT 格式都可以精确控制。

三、NPR 卡通渲染体系

角色光照模型

原神角色光照核心公式（伪代码）：

half NdotL = dot(N, L) * 0.5 + 0.5;
half rampU = NdotL * shadowMask;            // 用 ShadowMap 调制
half3 diffuse = tex2D(rampMap, float2(rampU, materialID)).rgb;

// 高光：阶梯式 cutoff，不连续插值
half spec = step(specThreshold, NdotH);
half3 specColor = spec * specIntensity * matSpec.rgb;

// 边缘光（Rim）增强立体感
half rim = pow(1.0 - NdotV, rimPower) * rimMask;

color = diffuse * baseColor + specColor + rim * rimColor;

多层描边

  • 背面外扩法：模型背面沿法线外扩 0.005~0.02 米，绘制纯色，构成主轮廓
  • 顶点色控制描边宽度：脸颊/手指等区域用顶点色 R 通道压低粗细，避免肉饼脸
  • 内勾线：法线贴图 + 屏幕空间梯度判别（不开 SSAO 时用此简化版）
  • 移动端低档位：仅做背面外扩，不做内勾线

面部分区控制

原神角色脸部使用 世界空间方向参考贴图，避免角色脸朝任何方向都不出现"过曝鼻子"。

  • SDF 面部贴图 R 通道：左半脸到右半脸的 SDF
  • 采样时根据光源方向计算面部光暗分界，强行 cutoff
  • 结果：阴影边界稳定，不会随头部 yaw 变化产生鬼影

四、开放世界场景渲染

地形

  • 高档：Tessellation + 多层 Splat + Triplanar 砾石
  • 移动端：去 Tessellation，2~4 层贴图混合
  • 使用 SVT（Streaming Virtual Texture）解决多层贴图 sample 数过多

植被

  • 近：完整 Mesh，GPU Instancing
  • 中：LOD 简化模型 + Billboard 树叶簇
  • 远：Imposter（多角度烘焙的预渲染图）
  • 风场：CPU 高度图 + Vertex Shader 偏移

建筑/室内

  • 整套 PBR Material，移动端关闭 Detail Map
  • 室内用 Reflection Probe + Light Probe Volume
  • 窗内"假室内"用 Interior Mapping（Cubemap 视差）

HLOD / 远景

  • 整片区域 baked 成单 Mesh + 单 Texture（HLOD）
  • 远景仍保留剪影特征，弱化贴图细节
  • 切换距离按机型分档

五、天气与时间

  • 实时时间循环（约 24 分钟一天）：太阳/月亮 elevation 实时变，影响 Ramp 上的 shadow 区域
  • 天空盒：分层云（Volumetric Cloud 简化版） + 大气散射 LUT
  • 雨：粒子 + 屏幕空间湿度（高档）/ 仅角色头顶 splash（低档）
  • 雪：地表覆盖度通过 World Y + Normal Y 计算，实时切换不烘焙
  • BGM 与天气联动通过事件总线，不在渲染层触发

六、水体与流体

  • 主世界水面：法线动画 + 屏幕空间反射（高档）/ Cubemap 反射（中低档）
  • 水边发白：Depth Buffer 差值，浅水显白沫
  • 角色入水波纹：动态 RT 写入水面 displacement，PS5 用 Compute Shader，移动端简化
  • 枫丹版本（4.0）的 水下渲染：扭曲 + 蓝色调 + 焦散投影（Caustics 贴图 UV 滚动）

八、移动端性能策略

分档策略

  • 4 档：极低/低/中/高，自动检测（含 GPU 型号、温度、电池）
  • 分档不重做美术，只调：分辨率、Shadow 级数、CSM 分辨率、植被密度、特效粒子上限、Imposter 切换距离
  • 新版本上线前会用机型样本跑性能回归

带宽优化

  • SceneColor 用 R11G11B10 而非 RGBA16F，节省 50% 带宽
  • Shadow 与 BasePass 之间使用 RenderPass 合并（Vulkan/Metal）
  • Tile-based GPU 上严格遵守 Load/Store Action（如 Don't Care）

内存压力

  • 5.0 之后地图扩张严重，开启 分块加载（Chunk Streaming）
  • 角色资源 LRU 缓存：常用 12 个角色 + 队伍 4 个常驻
  • 纹理压缩：Android ASTC 6×6 / iOS ASTC 4×4 + Sliced Texture（mip biased loading）

九、关键启示

对 NPR 项目的启示

  1. 面部 SDF 是脸部光影稳定性的关键
  2. 描边方案要分档，不要一刀切背面外扩
  3. NPR 不等于"低成本"，工业化体系成本比 PBR 还高

对开放世界手游的启示

  1. SVT/Triplanar 是地形多层贴图的必经之路
  2. Imposter 是远景植被性价比之王
  3. HLOD 不只是远景优化，也是内存优化的核心
  4. 跨平台一致性要靠"参数化"，不要平台分支多套代码
