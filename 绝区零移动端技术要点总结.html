一、核心结论速览

渲染策略

  • 移动端 前向 + 自定义 SRP，米哈游第三代 NPR 体系
  • 城区与副本两种差异极大的视觉风格共用一套底层管线
  • 大量"动作捕捉级"演出，移动端动态降级

核心技术

  • 角色：原神/星铁体系 + 布料/挂件物理
  • 副本：屏幕空间 漫画格子分镜（Comic Frame）
  • 战斗触发屏幕空间 Halftone / 网点 / 速度线

预算/Format

  • SceneColor R11G11B10 + 单独漫画 RT
  • Shadow 1~2 级 CSM
  • 动态分辨率 540P~1080P
绝区零最特别的地方
绝区零不是简单的"米哈游公式 +1"，它在副本（空洞）中大量使用 漫画分镜 + 屏幕空间网点，本质上是把 2D 漫画美学塞进 3D 实时渲染。
这意味着技术目标从"3D 像 2D"升级为"3D 装作是漫画"。

二、双场景架构（城区 vs 副本）

场景视觉风格玩法渲染特点
新艾利都（城区）都市开放，类 GTA 街区探索、剧情、商店光照偏写实，UI 拟物化
空洞（副本）漫画分镜 + 异空间战斗、Roguelike 推进俯视格子地图 + 3D 战斗切换
战斗实时3D 透视 + 屏幕特效连击、闪避、技能大量后处理触发，速度线/网点叠加
过场动画电影级 / 卡通分镜剧情切换预渲染 + 实时混剪

三、渲染管线与 Pass 顺序

Pass 1 · ShadowMap

城区 2 级 CSM；副本简化为 1 级或仅角色阴影。

Pass 2 · Opaque BasePass

地形 → 城市建筑 → 街道道具 → 行人/敌人 → 玩家。城区开 SSAO（高档），副本关。

Pass 3 · Outline

角色描边，副本中可强化为粗线条以增强漫画感。

Pass 4 · Comic Overlay（仅副本/战斗）

屏幕空间 Halftone（半色调网点）、速度线、爆炸图案。这一 Pass 在城区可全跳过。

Pass 5 · Transparent / FX

能量护盾、技能粒子、武器轨迹。

Pass 6 · PostProcess

Bloom + Tonemap + 战斗时叠加 Chromatic Aberration / Vignette。

四、角色 NPR 与时尚化

角色质感升级

  • 沿用米哈游 NPR 框架（Ramp + 描边 + 面部 SDF）
  • 新增：布料动力学 + 挂件物理（书包、铃铛、围巾）
  • 头发分两层：底层用 Ramp 简化，顶层用 Mesh 高光带
  • 眼睛更夸张："星形高光"通过单独贴片实现

时尚 / 多套装

  • 每个角色多套外观，使用 模块化骨骼，主体骨骼共享
  • 装饰品（鸭舌帽、挂件）是独立 Mesh，绑定到子骨骼
  • 切换装扮无需重启战斗，运行时切 Material + Mesh

五、连击特效与分镜

街机动作美学
绝区零战斗的核心观感在 "打击瞬间感"——这要求大量屏幕空间 + 时间停顿 + 漫画式爆点。

典型连击瞬间效果

事件视觉表现实现
普攻命中白色冲击波屏幕空间 Radial Gradient + 时间衰减
极限闪避慢动作 + 蓝色色调Time Scale + Color Grading 临时切换
连携技角色立绘弹出 + 漫画背景UI Layer 临时遮罩 + 速度线
终结技全屏分镜 + 爆炸图案切相机至专属舞台 + 漫画 RT 合成

屏幕空间漫画特效

  • Halftone：根据像素亮度采样网点贴图，调制 alpha
  • 速度线：极坐标变换 + 噪声 mask，向中心收敛
  • 爆炸星形：Mesh 贴片 + Emissive 动画，拉至屏幕中心
  • 边框：副本场景固定漫画格子边缘叠加，可作为 UI 元素

六、空洞副本的"漫画格子"渲染

空洞玩法本质是 俯视格子推进——玩家选择移动到下一个 Cell，每个 Cell 触发不同事件（战斗/谜题/商店）。这种俯视格子"地图"用 2.5D 漫画分镜 风格呈现：

  • 固定俯视 + 浅斜俯角，格子之间用漫画风格连接线
  • 每个 Cell 是预制 mini scene，相机过渡有强动效
  • 进入战斗时镜头从俯视 dive 到第三人称，实时切换，不切场景
  • 这套相机 + 风格切换是绝区零最具识别度的部分

八、移动端性能策略

分场景预算

  • 城区是性能瓶颈：行人/动态光源/反射多。低档关 SSAO + 行人密度降一半
  • 空洞节点切换利用 异步加载，下个 Cell 资源后台预读
  • 战斗大招触发 动态分辨率下调（1080→720），结束恢复

特效预算

  • 连击 chain 时同时存在的特效可达 30+ 个，用 事件队列限流，超出阈值合并
  • 屏幕空间 Halftone/速度线/爆炸是 UI Composition，不进 3D Pass
  • 空气墙/特效粒子在低档退化为 mesh-based 假特效

分档

  • 低/中/高/超高/极高，旗舰机推 60/90/120 fps 三档
  • 低档：540P + Bloom 关 + 漫画分镜简化为单帧静态贴图
  • 中档：720P + 完整漫画分镜效果 + 30 fps 战斗
  • 高档：1080P + 60 fps + 全部后处理

九、关键启示

对动作手游

  1. 连击观感来自"打击瞬间"，不是"高分辨率"
  2. 屏幕空间特效（Halftone/速度线）性价比极高
  3. 动态分辨率必须有，大招瞬间是必降时机

对风格化项目

  1. 3D 装作 2D 是趋势，但需要严格的 NPR 体系工业化支撑
  2. 漫画分镜 ≠ 简化，反而比 PBR 更复杂（多 RT 合成）
  3. 不同场景可以拥有"不同的视觉语言"，但管线必须复用
