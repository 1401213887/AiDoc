一、核心结论：分级方案的统一心智模型

① 档位 ≠ 几档

  • 头部手游 4~6 档是常态（FPS 偏好 5+ 档，UGC 派对 4 档）
  • 档位多 ≠ 画质好，差异在于"可关闭的维度"
  • FPS 类通常 抗锯齿 / 阴影 / 帧率 必分离
  • MMO / UGC 通常 画风/特效/帧率 打包

② 引擎机制三大底座

  • UE DeviceProfile + Scalability，3 个基线（Low/Mid/High）
  • Unity URP QualitySettings + Adaptive Performance + SystemInfo
  • 自研 多走"档位即数据表"模式（米哈游/网易/腾讯天美常见）

③ 数值三大轴

  • 渲染精度：0.6 ~ 1.2 倍屏分辨率（最敏感）
  • 阴影 / AO：CSM 级数 + 分辨率（512~4096）
  • 帧率档：30/40/50/60/90/120/144 七档最常见
总体取舍
移动端画质分级的本质是 "GPU 预算的有限维度拆解"。端游可以"全拉满"，手机必须明确把 有限的几毫秒 GPU 预算 分配到 最影响视觉锚点 的几个维度——通常就是 渲染精度 + 阴影 + 后处理 3 项。其余维度（特效、植被、远景）按机型直接砍。波哥之前的 Unity 风格锚点文章里讲得对："先锁定视觉锚点，再分档"，不要反过来。

二、概念辨析：画质 / 帧率 / 分辨率 / 特效

玩家口中的"画质"实际是 4 个独立维度的混合体，手游分级方案首先要把这 4 个维度解耦才能精细管理：

维度是什么性能敏感点玩家侧感知手游可调范围
渲染精度 Resolution Scale场景渲染分辨率 / 屏幕分辨率GPU 像素填充（移动 GPU 致命项）清晰度、锯齿0.6 / 0.8 / 1.0 / 1.2
画质等级 Quality Preset综合预设（包了 5~10 个开关）综合开销整体观感4~6 档
帧率 Framerate目标 FPSGPU 总负载 + 系统调度操作流畅度30/40/50/60/90/120/144
特效/风格 FX & Style粒子/光晕/风格化 LUT粒子 overdraw打击感/沉浸低/中/高 或 开/关
常见误区
① 帧率 ≠ 画质。FPS 是独立维度，把它和画质"绑定"是商务/玩家教育问题，不是技术问题。② 抗锯齿不是越高越好，1080P 以下开 TAA 收益大、720P 开 MSAA 浪费。③ 动态模糊省的是"帧率"不是"画质"，开动态模糊可以掩盖 30→60 帧的割裂感。④ 阴影最影响"是否有立体感"，低档关阴影是性能收益最大、视觉损失也最大的一刀。

三、引擎机制：UE Scalability 与 Unity URP QualitySettings

Unreal Engine · Scalability + DeviceProfile

UE 用 Scalability.ini 配每一个 feature（Shadow/Foliage/PostProcess/Effects）的 quality level（0~3），用 AndroidDeviceProfiles.ini 把这些 level 映射到具体机型。

  • 基线 profile：Android_Low / Android_Mid / Android_High
  • GPU 家族细粒度 profile：如 Android_Adreno740_High
  • 启动时按 BaseDeviceProfiles.ini 的 MatchProfile 规则匹配（按 GPU/GLES 版本/设备名）
  • r.MobileContentScaleFactor 决定整渲染分辨率

Unity · URP QualitySettings + Adaptive Performance

Unity 走的是 质量等级 (Quality Level) 路线，每一档是一个完整的 Asset 替换（材质/SH/LUT），再用 Adaptive Performance 包做运行时降级。

  • 推荐 3 梯队划分：高性能 / 均衡 / 基础（按 GPU + 内存 + 纹理压缩）
  • SystemInfo API 抓 GPU/内存/支持的纹理压缩格式
  • URP 的 UniversalRenderPipelineAsset 可配：MSAA/HDR/SRP Batcher/MSAA Samples
  • Scalable HD（使命召唤手游自研）：把以上打包成"画质等级"对外暴露

跨端共通：动态分辨率（DRS）与超分

  • DRS（Dynamic Resolution Scaling）：当帧率掉到阈值时，自动降低渲染比例。UE 通过 r.DynamicRes.OperationMode 控制，Unity 通过 DynamicResolutionHandler。
  • FSR / DLSS / MetalFX：超分技术，用低分辨率渲染 + AI 升采样到屏幕分辨率。《巅峰极速》公开声明引入 FSR + VRS 降低功耗发热。
  • VRS（Variable Rate Shading）：屏幕不同区域用不同着色率，UI/远景 1×1、人物中心 2×2。Adreno 6 系起支持，移动端新质价比手段。

四、八大分级维度拆解（核心数值范围）

把"画质"展开成 8 个可独立控制的维度，每一款头部手游的分级方案都是这 8 个维度的不同组合。下表给出典型范围与对 GPU 预算的影响权重：

实战口诀
"先砍渲染精度，再砍阴影，最后砍后处理"。这三个加起来占移动 GPU 预算约 70%。特效/植被是锦上添花，砍了对竞技体验影响小。

档位数与品类关系
FPS/战术竞技 = 5~6 档（和平精英、使命召唤、三角洲、永劫、暗区），档位多是为了让"画质 vs 帧率 vs AA vs 阴影"完全解耦；MMO/开放世界 = 4~5 档（原神、鸣潮、绝区零、燕云、星铁）；UGC/休闲 = 3~4 档（蛋仔、第五）；体验向 = 2~3 档（光遇，机型适配决定上限）。

六、标杆深拆 · 永劫无间 6 档分级

永劫无间手游是国内首款公开把画质分成 6 档的头部 UE4 大逃杀。公测后逐步解锁"精致→极致→终极"，是当前分级颗粒度最细的移动端案例。

6.1 六档划分与关键效果

① 流畅档（入门：骁龙 730G/天玑 800 起）

所有特效最低、模型简化、植被密度最低。目标：4GB RAM 设备 30 帧稳定。适配老旧机型（荣耀 X50 GT / iPhone 11）。

② 标准档（中端：骁龙 855/天玑 1000+ 起）

打开实时阴影、降低水面反射、简化粒子。目标：6GB RAM 设备 45 帧稳定。开始有"武侠美学"雏形。

③ 高清档（中高端：骁龙 8+ Gen1/天玑 9000+ 起）

开启高质量阴影、多级 CSM、特效全开、植被密度 +50%。首次开放 60 帧。适配 Redmi K70 / iQOO 12 / iPhone 14 Plus。

④ 精致档（高端：骁龙 8 Gen1/天玑 9000 起）

进一步提升贴图精度、阴影分辨率、动态全局光。关键过渡档，从"标准手游画面"切到"端游级画面"。

⑤ 极致档（旗舰：骁龙 8 Gen2+/天玑 9200+/A16 起）

关键新技术集中档：可交互风场、物理天空、体积雾、实时动态全局光。画面表现媲美端游。仅 8GB+ RAM 设备开放。iQOO 11（骁龙 8 Gen2）实测 60 帧稳定。

⑥ 终极档（PC 模拟器专属）

渲染分辨率拉到极限、开启全部 UE 移动端不支持的端游级效果（如完整 Lumen、虚拟几何体），仅 PC 模拟器开放，故意制造端手差距。

6.2 跨端分级背后的设计取舍

  • 极致档只对旗舰开放，避免中端机"看得见跑不动"的体验崩溃
  • 终极档专属 PC 模拟器，游戏设计上故意制造"端手差距"作为付费/迁移驱动力
  • 官方明确提到"极致拥有移动平台最好的表现效果"，但相比精致仅提升渲染分辨率 + 新增 4 项效果，避免"加 1 档就贵 50% GPU"的断层
  • 同时支持"游戏帧预测"，在更低功耗下提供流畅画面（有少量瑕疵），相当于"软降级"开关
经验
永劫的 6 档分级不是平铺的 6 档，而是 4 档可用 + 1 档"质变档" + 1 档"端游专属档" 的非线性分布。质变档（极致）必须独占一个旗舰机型才能跑的强技术点（如动态全局光），让最高档的视觉锚点立得住，否则就是无效加档。

八、避坑清单：高档位的"反作用"

8.1 高档位的反作用

① 阴影影响可见度（FPS 类致命）

和平精英、暗区突围、使命召唤的高画质阴影会让"伏地魔/阴影中敌人"难以发现。竞技玩家反而主动关阴影——这不是性能问题，是视觉反作用。分档方案要给"竞技预设"留开关。

② 高档 AA 在低分辨率浪费 GPU

720P 渲染时开 MSAA 4x 几乎看不到效果、但 GPU 翻倍。AA 档位应与渲染精度联动：渲染精度 ≤ 0.8 时强制 FXAA 或关 AA。

③ HDR 模式在 SDR 屏幕"伪开"

王者荣耀的"极致 + HDR"在不支持 HDR10+ 的屏幕上不会提升亮度范围，仅替换炫彩管线。部分玩家反馈"开启 HDR 后画面反而变暗"——因为管线替换了而非真 HDR。

④ 超高画质档在弱散热机型反向劣化

燕云十六声公测初期"画质与帧率二选一"的设计即源于此：高画质 + 高帧率在骁龙 8 Gen2 上跑 5 分钟即触发降频。高档必须考虑散热曲线，不能只看峰值性能。

⑤ "光追"在移动端是"部分效果"

暗区突围的"光线追踪"实为 Vulkan Ray Query 反射（GDC 2024 演讲），不是完整光追。不要被宣传语误导，移动端"光追"≠ 端游光追，多数只覆盖反射/阴影子集。

⑥ 插帧 ≠ 真高帧率

鸣潮"90~120 帧"实为插帧实现，存在延迟、画面割裂。原神、星铁的 60 帧为原生。档位名称里要明确"原生 vs 插帧"，否则玩家对延迟的投诉会爆炸。

8.2 分级方案设计的常见错误

  • 档位太密：5 档和 6 档玩家几乎感受不到差异，不如 4 档清晰
  • 档位断层：高档 GPU 预算比中档贵 80%，玩家一拉满就掉帧
  • 绑定销售：把"画质"和"帧率"绑死（必须高画质才能开 60 帧），FPS 类必被骂
  • 不解释代价：不告诉玩家"开启此选项会降低帧率"，引发"明明开了最高却卡"的误解
  • 无 DRS 兜底：不做动态分辨率，高档跑不动时直接掉到 20 帧

九、落地 Checklist 与决策树

9.1 设计阶段 Checklist

  1. 明确目标机型分段：至少 3 段（入门/中端/旗舰），参考上表映射
  2. 确定档位数：FPS = 5~6 档，MMO = 4~5 档，休闲 = 3~4 档，体验向 = 2~3 档
  3. 解耦"画质 / 帧率 / 渲染精度"：三者是独立维度，给玩家单独开关
  4. 优先砍 3 项：渲染精度 → 阴影 → 后处理（占 70% GPU 预算）
  5. 保留"竞技预设"：FPS 类必备"流畅 + 极限帧率 + 阴影关"一键
  6. DRS 必须常驻：避免高档跑不动时直接崩帧
  7. 加档必须有"质变"：每个最高档独占 1~2 个旗舰专属效果（动态全局光/光追/VRS 等）
  8. 配套"开启后效果展示"：鸣潮 3.2 已加——玩家点开看预览再决定

9.2 决策树：玩家侧

  1. 游戏主目标是什么？竞技上分→ 帧率优先，画质降到能稳定目标帧率为止
  2. 设备散热好吗？差→ 不开最高档，开 DRS 兜底
  3. 屏幕分辨率多少？≤ 720P→ AA 直接关或 FXAA，≥ 2K→ 开 TAA/SMAA
  4. 屏幕刷新率多少？60Hz→ 帧率档设 60；120Hz→ 帧率档 90~120
  5. FPS 类？→ 关阴影 / 关动态模糊（视觉反作用）
  6. MMO/开放世界？→ 关体积雾 / 降植被密度（收益最大）

9.3 性能定位工具

  • UE：stat unit / stat gpu / stat rhi / Unreal Insight
  • Unity：Frame Debugger / Profiler / Adaptive Performance Inspector
  • 设备侧：Snapdragon Profiler（SDP）/ PerfDog / SoloPi
  • 分档验证：在目标机型上跑 30 分钟稳定性测试，观察降频曲线而非峰值
