一、核心结论速览

渲染策略

  • 自研引擎，移动端 Forward + 自定义后处理
  • 极简几何 + 极强光影氛围
  • 体积云为美术核心资产，是引擎独家亮点

核心技术

  • 体积云：Ray Marching 实时计算
  • 大气散射：物理化大气 LUT
  • 披风布料：实时物理 + 风场互动

预算/Format

  • SceneColor R11G11B10 HDR
  • Cloud RT 单独 RGBA16F（高档）/ RGBA8 + 噪声扰动（低档）
  • 分辨率 720P~1080P 自适应
光遇为什么"特别"
Sky 是少数把"光影氛围"作为核心 gameplay 的产品。光线穿过云、风吹动披风、夕阳落到水面——这些不是装饰，是玩家体验本身。
这驱动 thatgamecompany 自研引擎，把体积云、物理光线追踪、风场布料做到移动端能跑。

模块能力

三、Pass 顺序与 RT

Pass 1 · ShadowMap

1~2 级 CSM，1024²。光遇关卡相对小，CSM 级数不需要太多。

Pass 2 · Atmosphere LUT

每帧根据太阳/月亮位置更新大气散射 LUT，驱动天空和角色环境光。

Pass 3 · Volumetric Cloud

分辨率 1/4 屏，Ray Marching 64~128 步。结果写入 Cloud RT，后续与 SceneColor 合成。

Pass 4 · Opaque BasePass

地形 → 建筑 → 角色 → 玩家。BasePass 中已采样 Cloud RT 做天空遮挡。

Pass 5 · Volumetric Light Shaft

体积光路径 Ray Marching，仅高档启用。低档退化为屏幕空间 Light Shaft。

Pass 6 · Translucency / Water

水面、披风半透部分、特效。

Pass 7 · PostProcess

Bloom（重度）+ Tonemap。光遇 Bloom 是核心氛围，从不会关。

四、体积云核心技术

云的几何表达

  • Density 函数：World Position 输入，返回 [0,1] 密度
  • 3D 噪声 + 2D 风格化云图组合
  • Curl Noise 让云有"流体感"，不是固定形状
  • Coverage 贴图控制大区域云量分布

Ray Marching 实现

  • 每个像素从相机出发，沿光线步进 64~128 步
  • 每步采样密度，累积透射率与散射光
  • Henyey-Greenstein 相位函数计算多次散射
  • 低档：步数减半 + 1/8 分辨率 RT

移动端优化

  • 1/4 分辨率 RT + 时序复用（TAA-like）
  • Early-out：透射率 < 0.01 提前终止
  • 预计算光照 LUT（每帧更新一次）
  • 抖动采样（Blue Noise）避免 banding

五、物理化光线追踪

光在《光遇》中的"角色感"
在光遇里，"光线"不是渲染概念，而是 gameplay 元素——玩家能"接住"光线、用光线点亮人物。这要求光线视觉上可识别、行为上一致。
  • 体积光（Light Shaft）：从云缝射下，体积 Ray Marching 实现
  • Bounce Light：物体表面反射光照 Probe，实时混合
  • 角色 Emissive：玩家点燃心愿后发光，影响周围环境光
  • 光线触发器：Gameplay 层用 Sphere Trace 检测玩家与光柱碰撞

六、角色与披风

极简 PBR

  • 角色面数极低，~3000 三角形
  • BaseColor + 简化 Mask
  • 面部贴图，无表情骨骼/Blend Shape（用动作和披风表达情绪）

披风物理

  • 披风是玩家飞行能量条的视觉化，必须流畅
  • 实时布料动力学，用简化 Verlet 积分
  • 风场模拟：CPU 高度图 + 顶点偏移
  • 移动端低档：用预制动画 + 部分顶点偏移近似

七、水面与天空

水面

  • Gerstner 波形 + 高档 SSR
  • 水面反射 Cloud RT，使云倒影出现
  • 水边沫与浅水通透感通过 Depth Buffer 差值

天空

  • 大气 LUT 驱动天空色彩
  • 太阳/月亮：单独 Mesh + 自发光，会被云遮挡
  • 极光：屏幕空间 Curl Noise + Emissive

八、移动端性能策略

体积云分档

档位RT 分辨率步数时序复用
低1/8 屏324 帧累积
中1/4 屏642 帧累积
高1/2 屏96无
极高全屏128无

关卡内存

  • 关卡间用"传送门"切换，全卸载旧关卡资源
  • 角色资源 LRU 缓存，社交场景缓存附近 8~16 个玩家
  • 纹理 ASTC 6×6（多数）

带宽与发热

  • 体积云 RT 是带宽大头，分档时直接降分辨率
  • 5 分钟后温度升，DRS 优先降云分辨率
  • Bloom 永不关，是核心氛围

九、关键启示

对氛围向产品

  1. 美术氛围 ≠ 高几何精度，光影才是核心
  2. 体积云、体积光、大气散射是氛围三件套
  3. Bloom 是氛围底色，不要简单 toggle

对自研引擎团队

  1. 体积云在移动端是可行的，但需要 1/4 分辨率 + 时序复用
  2. 大气散射 LUT 是物理化光照的基础设施
  3. 布料物理影响玩家情绪，必须流畅
