一、核心结论速览

渲染策略

  • Unity URP（自定义）+ 前向渲染
  • 极简光照 + 烘焙 Lightmap
  • 16 玩家同屏需要严格控制角色精度

核心技术

  • 角色：单层 NPR + 极简 Ramp
  • UGC 编辑器：Block 拼搭 + 实时光照
  • 物理：Q 弹角色控制器 + 简化布料

预算/Format

  • SceneColor RGBA8 LDR（多数档位）
  • Shadow 1 级 CSM 或 Blob
  • 分辨率 540P~1080P 自适应
蛋仔的工程定位
蛋仔的核心特殊性：① UGC 玩法，玩家自己创建地图——这意味着场景是运行时构造的，不能预烘焙；② 16 玩家同屏，每个玩家可换装；③ 低端机普及，目标用户大量使用千元机。

三、Pass 顺序与 RT

Pass 1 · ShadowMap（中档及以上）

1 级 CSM，分辨率 512²~1024²。低档完全用 Blob。

Pass 2 · BasePass

地形 → Block → 道具 → 玩家蛋仔。Lightmap 直采 + Light Probe。

Pass 3 · Outline（条件）

角色描边，可选。低档关。

Pass 4 · Transparent

水、特效、道具光环、UI 前粒子。

Pass 5 · UI

多人模式 UI 元素丰富（团队、计分、技能）。

Pass 6 · PostProcess

Bloom + Tonemap + Vignette（部分场景）。

四、UGC 编辑器的渲染挑战

UGC 的核心限制
UGC 地图无法预烘焙 Lightmap，因为玩家任意拼搭。但又不能完全实时 GI（性能不允许）。蛋仔的方案是 Light Probe Volume + 静态主光。

Block 拼搭系统

  • 每个 Block 是独立 Mesh + Material
  • 拼搭时实时计算邻接关系，做 Mesh 合并
  • 整张 UGC 地图运行时合成大 Mesh，减少 Drawcall
  • 场景内布置 Light Probe 网格（约 2m 间距），运行时插值

实时 GI 替代方案

  • 静态主光 + 简化阴影：太阳光位置可调，但相对场景固定
  • SH 球谐光照：每个 Block 生成简化 SH，实时插值
  • Hero AO：玩家脚下 Blob 阴影 + 接触点 AO 贴图

性能控制

  • UGC 地图限制 Block 总数（典型 1000~3000）
  • 提交时检查 Drawcall 上限
  • 违规地图（性能爆炸）后台扫描标记

五、蛋仔角色渲染

极简 NPR

  • 圆润角色，面数 2000~4000 三角形
  • 单层 Ramp 光照
  • 表情用 UV 偏移而非 Blend Shape（"贴脸"贴图）
  • 装扮系统：模块化 Mesh，绑到子骨骼

Q 弹变形

  • 跳跃/落地：顶点偏移做"压扁/拉长"变形
  • 受撞击：模型整体抖动 + 颜色暂时变红
  • 滚动：模型随地形法线倾斜，模拟惯性

装扮经济

  • 装扮是核心营收，每月 100+ 新装扮
  • 装扮用 Material 模板，避免新增 shader 变体
  • 翅膀/帽子/尾巴/挂件，全为子 Mesh，可独立组合

六、物理碰撞与 Q 弹效果

  • 角色控制器：胶囊 + 球形碰撞，简化为质点 + 阻尼
  • 16 玩家碰撞：物理引擎按距离 LOD，远距离玩家用近似碰撞
  • 道具物理：弹簧床、传送带、风扇、激光，均为预制物理交互
  • 同步：服务器仲裁 + 客户端预测，碰撞结果回滚 rare

八、极致兼容性策略

分档

  • 极低/低/中/高/超高，目标机型从 SD615 起
  • 极低档：540P + 关 Bloom + 关 Shadow + 简化角色装扮
  • 低档：720P + Blob Shadow
  • 中/高/超高：1080P + 60/120 fps

16 玩家同屏

  • 远距离玩家用 LOD 模型 + 简化装扮（仅显示头/身体，隐藏挂件）
  • 视野外玩家不绘制，仅同步逻辑状态
  • 团队模式按队伍批次绘制，减少 state change

UGC 防爆炸

  • 玩家创作地图限制 Block 总数
  • 提交时性能预测，过低评分的地图自动隐藏
  • 低端机进入复杂 UGC 地图自动降画质（独立配置）

九、关键启示

对 UGC 玩法

  1. UGC 地图不能依赖预烘焙，需要 Light Probe + SH 替代
  2. Block 系统提交前必须做性能审核
  3. 不同设备进 UGC 地图应自动降级

对休闲派对手游

  1. 糖果色风格依赖 Tonemap + 美术色板，不靠几何精度
  2. 16 玩家同屏关键是远距离 LOD + 装扮简化
  3. Q 弹角色变形用顶点偏移成本极低、效果佳
